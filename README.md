אתר מובייל־פירסט דו־לשוני עבור שירותי **טיפולים**, **שליחויות פרטיות** ויצירת קשר מהירה.

## מה קיים בגרסה הנוכחית

- ממשק עברית RTL ו־English LTR.
- מצב בהיר וכהה, הנשמרים במכשיר.
- קרוסלה מתחלפת בסדר: שליחות → עיסוי → שליחות → עיסוי → שליחות → עיסוי.
- בקשת טיפול: רפלקסולוגיה, עיסוי שבדי, עיסוי ספורטאים וכוסות רוח.
- בחירת קליניקה או הגעה לבית הלקוח, עם שיתוף מיקום והערת תמחור בהתאם למרחק.
- אמבטיית קרח בתוספת ₪25 בכפוף לאישור רופא.
- בקשת שליחות עם כתובות, שיתוף מיקום, חישוב מסלול ומחיר משוער.
- כפתור WhatsApp בולט בדף הבית ובתפריט. הוא יופעל כאשר יוגדר מספר העסק.
- מסך פרופיל הדגמה: שם, מייל, טלפון, מגדר, אווטר ותמונת פרופיל.

## מצב Firebase

הרשמה אמיתית, אימות מייל/טלפון, פרופילים מאובטחים והעלאת תמונות יופעלו לאחר אישור מכסת הפרויקטים של Google ויצירת פרויקט Firebase ייעודי. עד אז, מסך הפרופיל פועל כהדגמה מקומית בלבד ואינו שולח פרטי לקוחות לשרת.

## הפעלה מקומית

```bash
npm install
npm run dev
```

## יצירת חבילת פרסום

```bash
npm run build
```

תיקיית `dist/` היא חבילת האתר הסטטי לפרסום.

## פרסום ב־GitHub Pages

במאגר GitHub, עבור אל **Settings → Pages** והגדר:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/(root)`

לאחר ש־Pages פעיל, מחברים את `callphon.com` כדומיין מותאם אישית ומאמתים HTTPS לפני הפקת QR.
